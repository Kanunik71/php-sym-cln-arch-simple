Пользователь хочет подготовить спеку: $ARGUMENTS

Работай по правилам `docs/README.md`.

1. Прочитай `docs/README.md`, шаблон `docs/specs/_templates/spec.md` и
   релевантные разделы `api/CLAUDE.md`.
2. Определи следующий свободный номер: посмотри папки `docs/specs/NNNN-*` и
   возьми `NNNN = max + 1` (первая — `0001`).
3. Если пользователь не указал slug — предложи короткий `kebab-case` из
   названия фичи.
4. Создай `docs/specs/NNNN-<slug>/spec.md` по шаблону и заполни его на основе
   запроса и контекста репозитория.
5. **Не пиши код и не создавай `plan.md`/`tasks.md`.** Статус оставь `draft`.
6. Если критичных данных не хватает (границы, ошибки, доступы, масштаб) —
   задай не более 3–5 конкретных вопросов, не придумывай требования.

В конце покажи путь к файлу и список открытых вопросов.
