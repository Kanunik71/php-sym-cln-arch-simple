# 0001. Baseline-спеки описывают код, `CLAUDE.md` — целевое состояние

## Контекст

В репозитории есть два описания архитектуры, которые расходятся:

- `README.md`, `api/src/Application/CLAUDE.md`, `api/src/Infrastructure/CLAUDE.md`
  описывают фактический код: `Service::execute`, подпапки `Action` / `Query` /
  `Lifecycle`, `ValueObject` в `Application/`.
- `api/CLAUDE.md` описывает целевую архитектуру: слой `Domain/`,
  `Command` / `Query` / `CommandHandler` / `QueryHandler`, доменные события и
  исключения в `Domain/`.

Фактически в `api/src` нет `Domain/`, нет `Application/Command|Query|Handler`;
use cases реализованы сервисами. Принятие `api/CLAUDE.md` за источник истины
для описания текущего поведения привело бы к неверной документации.

## Решение

- **Baseline-спеки (as-is)** описывают **фактическое поведение кода и тестов**,
  имеют тип `baseline` и статус `implemented`.
- Источник истины для baseline — код (`api/src`) и тесты (`api/tests`).
- **Change-спеки (to-be)** описывают будущие изменения по процессу
  `spec → plan → tasks`.
- `api/CLAUDE.md` трактуется как **целевое состояние** и используется при
  проектировании изменений, а не как описание текущего кода.
- Расхождения кода с целевой архитектурой фиксируются в baseline-спеках в
  разделе «Известные расхождения» и при необходимости становятся отдельными
  change-спеками.

## Последствия

**Положительные**

- Документация соответствует реальному поведению.
- Целевая архитектура не теряется и остаётся ориентиром для рефакторинга.
- Расхождения видны явно, а не спрятаны.

**Отрицательные / цена**

- Нужно поддерживать и baseline, и целевые правила.
- При рефакторинге baseline-спеку придётся обновлять вместе с кодом.

## Альтернативы

| Вариант | Почему отвергнут |
|---------|------------------|
| Описывать только `api/CLAUDE.md` (to-be) | Документация противоречит коду, непригодна как as-is |
| Переписать `api/CLAUDE.md` под текущий код | Потеряется целевая архитектура и правила для новых изменений |
| Не документировать расхождения | Скрытые противоречия и неверные ожидания |
